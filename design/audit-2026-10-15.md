## Mesures

- Lighthouse mobile en ligne : accueil perf 85 / accessibilité 94 ; Castres perf 85 / accessibilité 93. SEO 100 partout, bonnes pratiques 96-100. CLS 0.
- Bloquant d'affichage : Google Fonts (~0,9 s) puis style.css (~0,2-0,3 s).
- Images les plus lourdes : travaux-forestiers.webp 317 Ko, vrd-viabilisation.webp 375 Ko, terrain-viabilise.webp 344 Ko, voie-acces-parking.webp 210 Ko.
- En-têtes : compression brotli, cache 1 an sur CSS versionné, CSP minimale, pas de HSTS.

## Défauts confirmés

1. **Erreur JS sur les 6 pages intérieures** : `js/main.js` l. 460, `lightbox` est null hors accueil → le script s'arrête. Effet visible faible aujourd'hui (rien d'utile après sur ces pages), mais fragile.
2. **Image à src vide sur l'accueil** : `index.html` l. 906 (`#lightbox-img`), comptée comme image cassée.
3. **« 15+ ans d'expérience »** sur 5 pages (stats + texte Castres, Labruguière, Mazamet) alors que `foundingDate` = 2023. À formuler comme l'expérience de Vincent, ou corriger.
4. **Titres et descriptions trop longs** sur les pages intérieures (titres 64-75 car., descriptions 161-183) → coupés dans Google.
5. **Logo illisible sur les pages intérieures** (texte sombre sur photo).
6. **Accessibilité** : `aria-label` sur des `div` sans rôle (carte, étoiles), liens tel/mail distingués par la couleur seule, contraste de l'email dans le bloc CTA des pages villes.
7. **Formulaire** : l'email est obligatoire, le téléphone facultatif ; pour un terrassier, beaucoup de clients préfèrent laisser un numéro.

## Les actions qui rapportent le plus

1. Avis Google (2 seulement) + vrais chantiers par ville → déjà demandés à Vincent (pilier SEO local).
2. Correctifs techniques en un lot (erreur JS, image vide, logo, contrastes, titres/descriptions, formulaire tel OU email).
3. Polices hébergées sur le site + images recompressées → LCP sous 2,5 s.
4. Ajouter un lien direct « Laisser un avis » sur le site et dans le pied de page.
5. Plus tard, en option : un vrai moment waouh (avant/après de terrain piloté au défilement) pour atteindre le standard de l'agence.

## Ce qui est déjà au niveau

SEO technique (100 partout, schéma complet, maillage entre toutes les pages), conversion (téléphone et devis partout), CLS 0, vraies photos, formulaire avec anti-spam, en-têtes de sécurité corrects.
